# HSL.dev — Personal Portfolio

Production-style developer portfolio for **Hariths Sufyan Lee**, built with React (Vite) and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (typically `http://localhost:5173`).

## Customize

- Content lives in `src/data.js` (projects, experience, skills, contact).
- Place a headshot at `public/profile.jpg`.
- Optional project stills: `public/projects/project1.jpg` … `project4.jpg`.
- Optional CV: `public/cv.pdf`.
- Update the LinkedIn URL in `src/data.js` if it differs.
